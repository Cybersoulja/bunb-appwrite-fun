⚡ Bun HTTP Function Starter
A powerful starter template for building HTTP functions with Bun. Ready to help you create something amazing! 🚀

🎯 Features
Simple and intuitive routing
JSON response handling
TypeScript support
Built-in logging
🛠️ Getting Started
Installation
bun install
Running Locally
bun run src/main.ts
